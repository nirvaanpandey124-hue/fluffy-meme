# Mini Turtle Shooter

A small space-shooter game made with Python's built-in `turtle` module.

## Play it locally

This game needs a normal desktop computer because Turtle opens a graphics window.

1. Install Python 3.
2. Download or clone this repository.
3. In a terminal inside the project folder, run:

   ```bash
   python turtle_shooter.py
   ```

## Controls

- Left arrow: move left
- Right arrow: move right
- Space: fire

## Note for Codespaces

GitHub Codespaces does not have a graphical display, so the Turtle version cannot run there. Run it locally on Windows, macOS, or Linux instead.
